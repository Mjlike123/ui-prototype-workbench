## 推荐手动下载方式

1. 在浏览器打开上方 Mobbin 链接并登录账号
2. 进入 TikTok iOS 项目页，按 Flow / Screen 浏览
3. 使用 Mobbin 提供的导出能力（如 Pro 批量下载 / Copy / Save）
4. 将导出的 PNG 放入本目录 `screens/`，并更新 `manifest.json`
