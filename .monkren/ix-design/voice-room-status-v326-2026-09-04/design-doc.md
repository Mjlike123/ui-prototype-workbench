## 1. 设计目标

### 1.1 背景

此前语音房「在房状态」仅好友可见。开放关系大区内，陌生人缺少了解用户当前是否在房的维度，影响社交发现与进房意愿。本期将可见范围扩展为可配置，并支持大区差异化默认策略。

### 1.2 用户与场景

| 用户 | 场景 | 核心任务 |
|------|------|----------|
| 陌生人/非好友 | 浏览动态或他人主页 | 发现对方在房并一键进房 |
| 房主/在房用户 | 希望被更多人发现 | 将可见范围设为「所有人可见」 |
| 注重隐私用户 | 仅好友知道自己位置 | 设为「仅好友可见」或开启隐身 |
| 全量用户 | 隐私设置 | 理解并控制在房状态谁可见 |

### 1.3 设计原则（本期）

- **单槽位状态**：在房与在线共用头像右侧位置，避免信息堆叠。
- **一点进房**：在房状态条可点击，直达对应语音房。
- **隐私可预期**：可见范围 + 隐身分层，规则可解释。
- **大区策略后端化**：默认选项由大区决定，前端展示当前生效值。

### 1.4 成功标准

- [ ] 陌生人（在「所有人可见」且未隐身时）可在主页客态与动态看到在房状态
- [ ] 点击在房状态可进房，埋点带来源
- [ ] 隐私设置可切换「所有人 / 仅好友」且立即生效
- [ ] 隐身开启后全场景不展示在房状态

## 3. 用户流程

### 3.1 主流程：发现并进房

```text
浏览动态/主页 → 看到「在语音房 / 进入房间」→ 点击 → 进入语音房
```

### 3.2 设置可见范围

```text
Me → 隐私设置 → 语音房在房状态 → 半窗选择 → 立即生效收起
```

### 3.3 优先级（状态是否展示）

```text
在线隐身开启？ → 是：全场景不展示在房
              → 否：按「仅好友/所有人」+ 查看者关系 + 大区/版本兼容判断
```

## 4. 页面说明

### 4.1 个人主页（客态）`profile-guest`

**目的：** 展示用户身份，并在可可见时提供进房入口。

**信息结构：**

| 区域 | 内容 |
|------|------|
| 头像区 | 头像 + **状态槽**（在线 OR 在房条） |
| 在房条 | 动效 icon + 「在语音房」+ 「进入房间」 |
| 底栏 | Add / Chat 等既有按钮 |

**交互：**

| 控件 | 操作 | 结果 |
|------|------|------|
| 在房条 | 点击 | 进入对方语音房（埋点：个人主页） |
| 返回 | 点击 | 返回上一页 |

**状态：**

| 状态 | 条件 | UI |
|------|------|-----|
| 在房可见 | 在房 ∧ 允许可见 ∧ 未隐身 | 显示在房条 |
| 仅在线 | 不在房或不可见在房 | 显示原在线状态或空 |
| 隐身 | 用户隐身 | 不显示在房 |

---

### 4.2 动态各表面 `feed-surfaces`

**范围：** 动态各 tab、话题详情、动态详情。

**展示：** 头像复用**线上在房样式**（非好友在满足可见策略时也可见）。

**交互：** 点击在房相关区域 → 进房（埋点：动态）。

---

### 4.3 隐私设置 `privacy-settings`

**新增行：**

- **标题：** 语音房在房状态  
- **辅助文案：** 可设置你的语音房在房状态可见范围，所有人可见或仅好友可见  
- **右侧：** 当前选项摘要（所有人可见 / 仅好友可见）

**交互：** 点击行 → 唤起半窗 `privacy-voice-room-sheet`。

**线框约定：** 交互稿省略状态栏时间；设置行不画「右侧当前值 + chevron」左右排布，改为标题 / 说明 / `当前：xxx` 纵向堆叠。实现仍按 Kit `meSecondaryActionRow` 右值 + chevronRight。

**默认（后端）：**

| 大区 | 默认 |
|------|------|
| 开放关系大区 | 所有人可见 |
| ME & KSA | 仅好友可见 |

---

### 4.4 语音房在房状态半窗 `privacy-voice-room-sheet`

**类型：** 自底部向上 action sheet。

**选项：**

1. 所有人可见 — 陌生人与非好友可见  
2. 仅好友可见 — 仅好友可见  

**交互：** 选择即生效并向下收起（PRD 正文）；若 Figma 含「取消/确定」以对稿为准。

**线框样式：** iOS 纯文字 action sheet——选项无卡片/描边，分割线分隔行；标题与说明**居中**；选中项标题加粗，不画勾选图标。

**特殊：** 用户已开「在线隐身」时，建议整行或半窗内提示隐身优先（设计补全）。

## 7. 兼容与规则

- **老版本用户：** 默认仅好友可见。  
- **老版本看新版本：** 即使对方设「所有人可见」，老版本也不可见对方在房状态。  
- **隐身于房间 / 在线隐身：** 隐身优先级最高，覆盖在房外显。
