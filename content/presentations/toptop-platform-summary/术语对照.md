# 内部分享 · 术语括号释义（与 PPT 一致）

| 术语 | 括号里怎么说 |
|------|----------------|
| specs/ | Git 里的组件契约 YAML |
| MDX | Portal 上的组件说明文档 |
| stable | 已验收、可正式引用的组件状态 |
| Token | 颜色/间距等语义变量（非手填色值） |
| kitGap | Kit 还缺的组件或规则清单 |
| explore | 探索原型，不能当研发像素基线 |
| Detach | 从 Figma 团队库实例解开，失去联动 |
| Hybrid | Kit 稳定锚点 + 临时模块混搭 |
| prototype | 待验证的创意/业务模块 |
| Portal | 设计系统网站（`npm run portal:dev`） |
| /canvas | 已登记原型的预览目录页 |
| Catalog API | Kit 结构化目录接口，给 Agent 读 |
| Skills | Cursor 里按场景选用的技能包 |
| P0/P1/P2 | 必改 / 应改 / 可改 |
| draft → review → stable | 草稿 → 评审 → 验收可引用 |
| 门禁 A / B | Portal+spec 一致 / Figma 标准实例稿 |
| npm run specs:validate | 校验契约 YAML |
| verify:mvp | 原型交付自检门禁 |

正文里已用灰色小字 `.hint` 标在术语后；若某处嫌挤，可只在首次出现保留括号。
