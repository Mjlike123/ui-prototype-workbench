## 使用场景

Toast 用于**短时、非模态**的操作反馈或状态说明，例如保存成功、复制完成、网络错误等。它不打断用户当前任务，通常在 2–3 秒后自动消失。

典型场景：

- 操作成功 / 失败 / 警示的即时反馈
- 加载中状态说明（配合 `loading` 图标）
- 可点击跳转的轻量提示（纯文案 + 右箭头）

不要用 Toast 承载关键决策、长段落说明或必须用户确认的信息（应使用中间弹窗或半屏）。

## 结构

| 模式 | 尺寸 | 组成 |
| --- | --- | --- |
| 纯文案 · 短 | 内容自适应（示例 140pt 宽） | 文案 + 可选 16pt 右箭头 |
| 纯文案 · 长 | 最大 200pt | 14pt 文案，最多两行 |
| 状态 · 短 | 100×100pt | 32pt 状态图标 + 单行文案 |
| 状态 · 长 | 200pt 宽 | 32pt 状态图标 + 最多两行文案 |

容器：圆角 12pt、背景 `color.toast.background`（rgba(47,48,57,0.9)）、文案 `color.text.white-primary` 14pt Regular。右箭头与所有状态图标统一使用和文案相同的 `color.text.white-primary`。

## 状态图标

| status | 图标 | 默认文案示例 |
| --- | --- | --- |
| `none` | 无 | 自定义 |
| `success` | 32pt 成功 | 成功提示 |
| `error` | 32pt 失败 | 失败提示 |
| `warning` | 32pt 警示 | 警示提示 |
| `loading` | 32pt 旋转加载 | 加载中 |

## 交互

- 默认仅展示，不拦截点击；自动消失由业务层控制挂载时长
- `showChevron` + `onPress`：纯文案短提示可点击，表示继续操作或跳转
- 同一时刻建议只显示一条 Toast；新提示替换旧提示

## 可访问性

- `role="status"`、`aria-live="polite"`
- 关键错误需有页面内冗余说明，不能仅靠 Toast
- 可点击短提示使用 `<button>` 并提供可读名称

## 与其他组件的关系

| 组件 | 关系 |
| --- | --- |
| `center-dialog` | 需要用户决策时用中间弹窗，不用 Toast |
| `in-room-notification` | 房间内沉浸场景用通知条，不用系统 Toast |
| `action-panel` | 操作选择用手势面板，不用 Toast |

## 避免

- 堆叠多条 Toast
- 用 Toast 替代表单字段级错误提示
- 关键流程只用 Toast 告知失败且不可回看
