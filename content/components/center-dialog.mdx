## 使用场景

中间弹窗用于**重要信息提示**或**需要用户决策**的短任务。它会打断当前页面，因此只用于关键操作；状态通知用 toast，非阻断补充信息用 popover 或半屏。

典型场景：

- 删除、退出、放弃编辑等二次确认
- 单按钮「我知道了」式重要说明
- 带「不再提醒」的可选确认

## 结构

1. **文字区**（上）：标题 18pt Semibold + 可选描述 14pt secondary，居中；可选 100pt 配图
2. **按钮区**（下）：单按钮或双按钮；与文字区间距 16pt，区内边距 24pt

容器固定宽 300pt、圆角 16pt、白底。

## 按钮布局

| 布局 | 视觉 | 使用时机 |
| --- | --- | --- |
| `single` | 260pt 通栏主按钮 | 仅需确认已读 |
| `horizontal` | 122pt + 122pt 横排，间距 16pt | 取消/确认、Discard/Save |
| `vertical` | 两个 260pt 通栏纵排 | 主操作需要更强强调 |

横排时：**左侧中性灰次要，右侧品牌主色**。纵排时：**主操作在上**。

## 可选「不再提醒」

显示在按钮区上方，14pt secondary 文案 + 24pt 复选图标。用于可记忆的用户偏好，不应替代主操作按钮。

## 呈现与关闭

遵循 `center-dialog-behavior`：

- 进入：蒙层 0→50%，弹窗 opacity 0→1，scale 0.85→1.03→1，**320ms**
- 离开：反向播放 **320ms**
- `dismissible=false`：只能点按钮关闭（警报型）
- `dismissible=true`：蒙层与 Escape 触发 `onDismiss`（如继续编辑）

## 与其他组件的关系

| 组件 | 关系 |
| --- | --- |
| `button` | 弹窗内按钮使用 40pt 档位 |
| `action-panel` | 半屏动作列表；多操作纵向列表用半屏而非中间弹窗 |
| `bottom-sheet-behavior` | `dismiss-confirmation` 使用中间弹窗呈现 |
| `center-dialog-behavior` | 动效、关闭与滚动规则 |

## 避免

- 在弹窗内塞入长表单或多步骤流程
- 警报型弹窗仅靠蒙层关闭
- 双按钮横排把主操作放在左侧
- 超过 70vh 仍不滚动中间内容区
