## 使用场景

图片空状态用于图片加载失败、尚未上传或业务暂无图的兜底占位。适用于 feed 封面、相册格子、消息图片等需要保持占位尺寸但不展示真实内容的区域。

## 结构与颜色

- 背景使用**单一实色**，不使用渐变、模糊或装饰图层。
- 亮色场景背景 `#E8E8E9`；暗色场景背景 `rgba(255, 255, 255, 0.1)`。
- 居中 `picture` 图标固定 **72×72pt**，亮暗各用独立切图：
  - `/icons/image-empty/picture-light.png`
  - `/icons/image-empty/picture-dark.png`

## 变体

- `theme: light` — 用于浅色页面或卡片。
- `theme: dark` — 用于深色页面或黑色承载面。

## 无障碍

容器提供 `aria-label` 描述暂无图片；图标切图对辅助技术隐藏。

## 避免

- 在空状态上叠加渐变、模糊或品牌装饰背景。
- 用 CSS 绘制 picture 图标，或混用亮暗切图与错误背景色。
- 把空状态当作可点击按钮，除非业务明确需要跳转上传流程。
