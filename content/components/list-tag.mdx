## 组成

列表标签用于用户列表中的紧凑身份信息，当前包含：

- `gender`：女性或男性，可选年龄数字。
- `membership`：会员 V1–V18 与 V99。

所有标签固定高 14pt，在消息列表用户名和摘要之间单行排列，标签间距为 4pt。

## 性别标签

纯性别标签为 14×14pt。性别符号视觉尺寸约 8pt，居中放置在 12×12pt 图标框中；需要展示年龄时，在图标框后增加 9pt Semibold 数字。容器左内边距 3pt、右内边距 4pt，图标框与数字间距 1pt。

女性使用 `color.identity.gender-female`，男性使用 `color.identity.gender-male`。图标资源来自 Figma，不使用文本符号或 CSS 重绘。

## 会员标签

会员标签使用正式 PNG 资源，覆盖 V1–V18 与 V99。统一按 14pt 高展示并保持原始宽高比，不裁切图案、不拆分图标与文字，也不在业务侧重新着色。

## 列表组合

当前消息列表只组合会员标和性别年龄标签，推荐顺序为：

1. 会员等级
2. 性别与年龄

标签行不得换行或挤压右侧时间；空间不足时由容器在末端裁切。身份含义通过标签可访问名称表达，内部图片视为装饰。

## 避免

- 在非用户实体或普通操作列表中使用身份标签。
- 将 14pt 标签任意放大以填充列表高度。
- 使用颜色作为性别的唯一表达。
- 用 CSS、emoji 或普通文字临摹会员图案。
- 让标签换行导致列表项高度变化。
