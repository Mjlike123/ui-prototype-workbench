## 使用场景

选择器按钮用于列表行、半窗选项或工具条中表达**选中 / 未选中**，例如举报原因单选、可见范围列表、话题筛选、Local 定位开关等。它强调“是否被选中”，不用于即时生效的设置型开关（请使用 `switch`）。

## 尺寸与布局

控件固定为 **24×24pt** 圆形，不得拉伸或改为胶囊形。在列表行中通常位于行尾；在工具条药丸内与文案并排，间距 4pt。

## 颜色

- 选中填充：`color.brand.primary`（#16D8C8）
- 选中对勾：`color.text.white-primary`
- 未选中描边：`color.border.image`（描边透明/bordBg2），描边宽度 1.5pt，并随明暗模式切换

## 状态

- **未选中**：空心圆 + 浅灰描边。
- **选中**：品牌色实心圆 + 白色对勾。
- **禁用**：保持当前选中位置，整体降低不透明度且不可点击。

## 交互

点击控件或关联 label 立即切换，并同步更新受控 `selected` 值。`selectionMode="single"` 使用原生 radio，并为同组控件提供相同 `name`；`selectionMode="multiple"` 使用原生 checkbox。视觉保持一致，不能用 checkbox 语义模拟互斥单选。

独立使用时必须提供 `aria-label`；与行内标题组合时，使用 `<label>` 包裹控件与文案。

## 与 Switch 的区别

|          | 选择器按钮         | 开关 Switch    |
| -------- | ------------------ | -------------- |
| 尺寸     | 24×24pt 圆形       | 44×27pt 胶囊   |
| 语义     | 选中 / 未选中      | 开启 / 关闭    |
| 典型场景 | 列表选项、半窗单选 | 设置页即时开关 |

## 避免

- 用 switch 或两个普通按钮模拟圆形选择器。
- 选中态改用系统绿色或其他非品牌主色。
- 在禁用态仍响应点击。
