## 使用场景

动作面板用于从底部弹出一组**互斥或并列的操作**，常见于资料编辑、内容管理、筛选确认等场景。它与完整半屏内容页（带分组按钮网格）不同：动作面板强调**纵向文字操作列表**，而不是复杂表单或 3 列按钮矩阵。

典型场景：

- 资料页点击「更多」后选择编辑、隐藏、删除
- 筛选流程中确认国家、年龄、年月等单选结果
- 需要附带一个即时开关说明（如 Hidden birthday）的设置型半屏

呈现动效、关闭位置、通底与滚动遮罩遵循 `action-panel-behavior`；嵌套与未保存确认遵循 `bottom-sheet-behavior`。

## 结构

自上而下：

1. **说明标题**（可选）：44pt 高，14pt Regular secondary，居中，容器顶部 8pt 内边距
2. **工具栏标题**（可选）：44pt 高，左返回、中标题、右确认；与说明标题互斥
3. **操作列表**：每项 64pt 高，16pt 居中
4. **4pt 浅灰分隔**（`#F3F5F9`）
5. **取消行**（推荐）：64pt 高，16pt Regular secondary
6. **底部开关行**（可选）：左文案 + 右 `switch`
7. **Home Indicator**：34pt 占位

面板顶部圆角为 `radius.16`（16pt），背景 `color.surface.panel`。

## 操作项语气

| 语气 | 视觉 | 使用时机 |
| --- | --- | --- |
| `default` | 16pt Regular primary | 普通中性操作 |
| `emphasis` | 16pt Semibold brand primary | 当前推荐、已选中或主路径操作 |
| `destructive` | 16pt Regular danger | 删除、退出、不可逆操作 |

同一面板中**最多一个** `emphasis` 项；`destructive` 应放在列表靠后位置，且需要业务二次确认。

## 标题区规则

### 说明标题

- 用于解释当前面板目的，不可点击
- 文案应简短，可多行换行，但避免超过 2 行
- 不需要返回/确认时使用

### 工具栏标题

- 左侧：24pt 返回，语义为返回上一级或关闭当前子层
- 中间：16pt Semibold 标题
- 右侧：16pt Semibold 品牌色确认文案（如 Confirm）
- 用于筛选、单选确认等需要显式提交的任务

## 取消与底部区

- **取消行**是信息阅读与任务型半屏的默认退出路径，文案通常为「取消」或 Cancel
- 取消区与操作列表之间必须有 **4pt** 浅灰分隔，不得省略
- 若同时存在取消与底部开关，顺序为：操作列表 → 分隔 → 取消 → 开关行 → Home Indicator
- 底部开关行复用 `switch` 组件，主文案 16pt，说明 14pt secondary

## 高度策略

Figma 中半屏弹窗支持固定比例（20% / 50% / 70% / 90% / 100%）与内容自适应两种模式：

- **动作面板**优先按内容自适应高度，不强行撑满屏幕
- 操作项数量较多时，列表区可滚动，但标题、取消与 Home Indicator 保持固定
- 预估超过 3 层嵌套时，改用完整页面而非继续叠加半屏

## 交互

### 动效（action-panel-behavior）

- **进入（250ms）**：蒙层 0%→50%，面板自底部 Y 轴滑入
- **离开（200ms）**：反向播放，焦点回到触发元素
- 与中心弹窗不同，动作面板不使用缩放动效

### 操作行为

- 点击操作项：执行业务回调并默认关闭面板（除非该操作会打开子层）
- `ActionPanelSheet` 默认 `closeOnAction=true`；操作项需要打开子层半屏时显式设为 `false`
- 点击取消：关闭面板，不提交变更
- 工具栏确认：提交当前选择并关闭
- 工具栏返回：返回上一级或关闭子层，遵循 `bottom-sheet-behavior`
- 蒙层点击与系统返回：关闭当前层，不得一次关闭全部嵌套层

### 高度与滚动

- 无底部主操作时面板可**通底**（仍保留 Home Indicator）
- 有底部通栏按钮且内容可滚动时，滚动区底部叠加 **20pt** 白色渐变，末项与按钮间距 **20pt**

## 可访问性

- 使用 `role="dialog"` 或 `role="menu"`，并提供可感知标题
- 每个操作项为 `<button>`，禁用态同步 `disabled`
- 返回、确认、取消必须有可读名称，不能仅靠图标或颜色
- 打开后将焦点移入标题或首个操作项；关闭后恢复到触发按钮

## 与其他组件的关系

| 组件 | 关系 |
| --- | --- |
| `button` | 半屏底部主操作（48pt 通栏）用于表单提交；动作面板内操作项为 64pt 文字行 |
| `switch` | 动作面板底部开关行复用开关组件 |
| `regular-navigation` | 工具栏标题区的返回/标题/文字操作布局与之类似，但动作面板固定在半屏容器内 |
| `action-panel-behavior` | 进入/离开动效、关闭位置、通底与底部渐变遮罩 |
| `bottom-sheet-behavior` | 嵌套、蒙层逐层返回与脏数据确认 |

## 避免

- 把 3 列小型按钮网格直接塞进动作面板（应使用半屏内容页 / Sheet 内容区）
- 省略取消行却要求用户只能点蒙层退出
- 在同一面板混用多个 emphasis 项
- 用 X 图标代替需要确认的 Cancel / Save 文案
- 操作项少于 2 个时仍使用动作面板（优先考虑 inline 按钮或完整页面）
