## 使用场景

发布状态通知用于**动态发布流程**中，在用户离开编辑页或回到 Feed 时，以非模态浮层提示当前上传进度与结果。它比系统 Toast 更具体：带缩略图、底部进度条，失败时可重试。

典型场景：

- 点击 Post 后展示 uploading…
- 上传完成展示「发布成功！」
- 网络或服务失败展示 post failed!，并提供重试与关闭

## 结构

| 区域 | 规格 |
| --- | --- |
| 容器 | 343×56pt、圆角 12pt、白底 + 浅描边 + 轻阴影 |
| 缩略图 | 32×32pt、圆角 4pt；无图失败态为灰底占位 |
| 文案 | 15pt Regular；上传/成功 `secondary`，失败 `danger` |
| 操作 | 仅失败态：24pt 重试 + 24pt 关闭 |
| 进度条 | 底部 2pt；上传/成功品牌色，失败警示色 |

## 状态

| status | 文案默认 | 进度条 | 操作 |
| --- | --- | --- | --- |
| `uploading` | uploading... | 部分宽度（随 progress） | 无 |
| `success` | 发布成功！ | 100% 品牌色 | 无 |
| `failed` | post failed! | 100% 警示色 | 重试 / 关闭 |

## 交互

- 上传中：只展示进度，不可手动关闭（业务可超时转失败）
- 成功：短暂停留后由业务层收起并跳转 Feed
- 失败：`onRetry` 重新发起发布；`onDismiss` 关闭通知并保留草稿

## 与其他组件的关系

| 组件 | 关系 |
| --- | --- |
| `toast` | 通用轻提示；发布流程优先使用本组件 |
| `feed-compose` | Core/Studio 发布页在发布时挂载本组件 |

## 避免

- 用通用 Toast 替代发布进度条
- 失败态不提供重试或关闭
- 同时堆叠多条发布状态通知
